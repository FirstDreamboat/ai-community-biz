## 三、项目背景速览

- **项目名称**：AI存量项目商机挖掘系统
- **建设方**：狄耐克（研发中心 / 信息中心牵头）
- **业务背景**："十五五"期间新开工改造城镇老旧小区 **11.5万个**，城市更新投资规模至少 **15万亿元**；存量社区智能化改造项目年增长率 **30%以上**。
- **核心痛点**：老旧小区改造项目信息分散于政府网站、招投标平台、住建公告等渠道，人工搜集效率低、商机响应慢。
- **核心目标**：构建从 **采集→解析→匹配→推送→跟进** 的全链路自动化商机挖掘系统，商机发现效率提升 5-10 倍。
- **关键指标**：商机日采集量 50-100 条/天、响应时间 ≤24 小时、销售线索转化率提升至 15-20%、全国区域全覆盖。

## 四、阅读顺序建议

1. **新成员入职/项目启动**：先读 `01` → `09` → `06`，再按分工读 `02/03/04/05`。
2. **产品/业务人员**：读 `01` 与 `10` 即可。
3. **开发排期对接**：以 `09` 为准，每日任务对照 `05`。
4. **测试人员**：以 `07` 为主，对照 `01` 的验收标准。
